> "모든 테스트 통과했습니다 ✅" — 한 번도 실행 안 했으면서.

AI 에이전트에게 **법을 집행하는** Claude Code 플러그인입니다.
직무별 AI법이 품질 기준을 조문으로 강제하고, 어기면 형벌·판결·반성문이 따라옵니다.

- 🧑‍⚖️ **직무 AI법 12종** (한/영) — 개발 · 디자인 · 기획 · 마케팅 · 글쓰기 · 번역 · 데이터 · 연구 · CS · 교육 · 인사 · 영업
- 🏛️ **입법 스킬** — 우리 팀만의 AI법을 대화로 제정·개정
- 📝 **반성문 장부** — 어긴 법은 기록되고, 다음 세션에도 따라갑니다. 재범하면 가중처벌
